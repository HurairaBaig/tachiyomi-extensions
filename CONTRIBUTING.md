# Contributing

Contributions are welcome for independently maintained extensions that connect to sources the contributor is authorized to access.

Before an extension is listed, provide:

- Public source code and its license.
- The exact Tachiyomi API/SDK compatibility target.
- A reproducible build process.
- APK package name, version, language, and source metadata.
- A checksum and a verifiable release artifact.
- Confirmation that the source is lawful to access and does not bypass access controls.

Do not submit extensions that distribute manga, evade paywalls, defeat DRM, or scrape services without authorization. Do not submit APKs of unknown origin.

The repository index must accurately match the APK artifact and the metadata expected by Tachiyomi.
